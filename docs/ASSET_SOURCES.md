# GAME GTA — asset sources and licence record

Only redistribute assets whose licence explicitly permits inclusion in this repository and browser games. Never copy GTA game rips, copyrighted voice lines, or assets without redistribution permission.

## Character and animation candidates
- Quaternius Universal Base Characters: https://quaternius.com/packs/universalbasecharacters.html
- Quaternius Universal Animation Library: https://quaternius.com/packs/universalanimationlibrary.html
- Quaternius Universal Animation Library 2: https://quaternius.com/packs/universalanimationlibrary2.html

These packs are catalogued as CC0. Confirm the licence bundled with the exact downloaded archive before committing it. Use GLB/glTF exports; retarget animation clips to the selected humanoid rig for Three.js.

## Sound candidates
- Kenney RPG Audio (footsteps/foley): https://kenney.nl/assets/rpg-audio
- CC0 effects catalogue (vehicles, ambience, impacts): https://kaino.dev/library/sfx

Check each original clip and preserve its licence record in assets/audio/LICENSES.md. Required production categories: engine idle/rev/acceleration, tire and door sounds, layered city ambience, footsteps on multiple surfaces, melee impacts, weapon reports/reloads, and UI sounds.

## Player voice
The browser supports loading personal audio recordings for keys 1–4. Files remain in the current browser session; they are not uploaded to the repository. Use recordings you own or are authorized to use.
