# راهنمای تست نسخه آزمایشی GAME GTA V1

## روش اجرا روی XAMPP

1. از مخزن GitHub شاخه `main` نسخه ZIP بگیر یا پروژه را دانلود کن.
2. پوشه را با نام دقیق `game_gta` در `C:\\xampp\\htdocs\\game_gta` قرار بده.
3. Apache را از XAMPP Control Panel روشن کن.
4. این نشانی را در Chrome یا Edge دسکتاپ باز کن: `http://localhost/game_gta/`
5. ابزار توسعه مرورگر را با `Ctrl+Shift+I` باز کن (در صورت کار نکردن، از منوی مرورگر > More tools > Developer tools استفاده کن).
6. در تب Console خطای قرمز را بررسی کن؛ در تب Network فیلتر JS را انتخاب کن و مطمئن شو فایل‌های `game.js`، `character.js` و `audio.js` با وضعیت 200 بارگذاری شده‌اند.

## چک‌لیست تست دستی

- [ ] صفحه شروع بدون خطای PHP یا صفحه سفید نمایش داده می‌شود.
- [ ] دکمه «شروع بازی» صحنه سه‌بعدی را فعال می‌کند.
- [ ] شهر، ساختمان‌ها و شخصیت آزمایشی دیده می‌شوند.
- [ ] W/A/S/D حرکت می‌دهد و Shift سرعت را افزایش می‌دهد.
- [ ] Space پرش می‌دهد و C حالت خم‌شدن را تغییر می‌دهد.
- [ ] حرکت ماوس دوربین را می‌چرخاند؛ چرخ ماوس فاصله دوربین را تغییر می‌دهد.
- [ ] Esc قفل ماوس را آزاد می‌کند و کلیک دوباره آن را فعال می‌کند.
- [ ] شخصیت نمی‌تواند از داخل ساختمان‌ها عبور کند.
- [ ] با نزدیک‌شدن به خودرو پیام سوارشدن ظاهر می‌شود؛ E سوار و پیاده می‌کند.
- [ ] خودرو حرکت می‌کند و از ساختمان‌ها عبور نمی‌کند.
- [ ] راهنمای بازی باز و بسته می‌شود و پس از بستن قابل دسترسی مجدد است.
- [ ] دکمه صدا، صدای تولیدشده قدم و موتور را روشن/خاموش می‌کند.
- [ ] بارگذاری فایل GLB محلی خطای غیرقابل‌مدیریت ایجاد نمی‌کند؛ انیمیشن فقط در صورت وجود کلیپ مناسب اجرا می‌شود.
- [ ] فایل صوتی شخصی در یکی از خانه‌های ۱ تا ۴ بارگذاری و با کلید مربوط پخش می‌شود.
- [ ] با تغییر اندازه پنجره، صحنه از قاب خارج نمی‌شود.
- [ ] حداقل ۱۰ دقیقه حرکت و رانندگی بدون توقف، صفحه سفید یا افت عملکرد شدید انجام می‌شود.

## محدودیت‌های شناخته‌شده

- Three.js از CDN بارگذاری می‌شود؛ بنابراین این نسخه برای اجرای فعلی به اینترنت نیاز دارد.
- مدل انسانی حرفه‌ای در مخزن قرار ندارد؛ بازی با شخصیت آزمایشی شروع می‌شود. مدل نمونه از منبع خارجی است یا می‌توان GLB محلی انتخاب کرد.
- صدای قدم و موتور فعلی افکت ساده تولیدشده با Web Audio است؛ فایل‌های صوتی نهایی و حرفه‌ای هنوز اضافه نشده‌اند.
- فیزیک خودرو و برخوردها ساده‌اند. سیستم مبارزه واقعی، شلیک، پلیس، ترافیک، مأموریت و NPC هوشمند جزو V1 نیستند.
